# رادار الوظايف 📡

موقع شخصي بيدوّر كل يوم الصبح على وظايف **DevOps / Cloud / Infrastructure / System Admin / System Engineer / SAP HANA** في مصر والخليج وأوروبا والريموت. بيقارن كل وظيفة بالـ CV بتاعك، ويقولك نسبة التوافق والمهارات الناقصة.

## التشغيل لأول مرة (حوالي 10 دقايق)

1. اعمل repo **public** جديد على GitHub، مثلاً باسم `job-radar`. لازم يبقى public عشان GitHub Pages يبقى مجاني.
2. ارفع الملفات من جهازك:
   ```bash
   cd job-radar
   git init
   git add .
   git commit -m "Job radar"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/job-radar.git
   git push -u origin main
   ```
3. من الـ repo روح على **Settings → Pages**، وتحت **Source** اختار **GitHub Actions**.
4. روح على **Settings → Actions → General**، وتحت **Workflow permissions** اختار **Read and write permissions** واعمل Save.
5. روح على تبويب **Actions**، اختار **Update jobs**، ودوس **Run workflow**. التشغيل بياخد من 3 لـ 10 دقايق.
6. الموقع هيبقى على الرابط ده:
   `https://<USERNAME>.github.io/job-radar/`

من بعدها الموقع بيتحدث لوحده كل يوم الساعة 6 أو 7 الصبح بتوقيت القاهرة.

> قبل أول تشغيل، الموقع بيعرض بيانات تجريبية بشركات وهمية عشان تشوف شكله.

## بعد أول تشغيل: افتح تبويب "المصادر"

هتلاقي فيه كل شركة وحالتها، شغالة ولا "مش لاقيها".

- **مش لاقيها** معناها إن الـ slug غلط، أو إن الشركة مش على نظام توظيف ليه API مفتوح.
- عشان تعرف الـ slug الصح، افتح صفحة التوظيف بتاعة الشركة وشوف الرابط. لو لقيته شكل `jobs.lever.co/xyz` أو `boards.greenhouse.io/xyz`، يبقى الـ slug هو `xyz`.
- لو الشركة على **Workday**، والرابط بيبقى فيه `myworkdayjobs.com`، حط `workday_url`.
- لو مفيش أي feed، حط لها `link: true`، وهتظهر في تبويب "ابحث بنفسك" كرابط بحث في LinkedIn عن وظايفها في أدوارك. ولو عندك رابط صفحة التوظيف الرسمية، ضيفه في `career_url`.
- أي شركة السحب الأوتوماتيك منها يفشل، بتظهر هناك لوحدها كرابط LinkedIn وجنبها علامة ↺.

## إضافة شركاتك

في ملف `config/companies.yml`، تحت آخر سطر، ضيف كل شركة بالشكل ده:

```yaml
  - {name: My Company, slugs: [mycompany], regions: [egypt]}
```

الـ `regions` ممكن تبقى `egypt` أو `gulf` أو `europe` أو `remote`. الرادار بيستخدمها عشان يتأكد إنه لقى الشركة الصح، لأن ممكن تكون فيه شركة تانية بنفس الاسم في أمريكا مثلاً.

## تحديث مهاراتك

في ملف `config/profile.yml` فيه قايمتين:

- `strong`: حاجات اشتغلت بيها في production، وبتتحسب 100%.
- `familiar`: حاجات اشتغلت بيها في مشاريع أو كورسات بس، وبتتحسب 60%.

لما تتعلم حاجة جديدة، زي `helm`، ضيفها في `familiar`. ولما تستخدمها في شغل حقيقي، انقلها لـ `strong`. وكل المفاتيح المتاحة موجودة في `radar/skills.py`.

وفي نفس الملف، تحت `filters`، تقدر تعدّل:

- `include_senior: true` لو عايز تشوف وظايف Senior كمان.
- `max_years_required` لو عايز تغيّر أقصى عدد سنين خبرة مطلوب.

## إزاي الفلترة بتشتغل

الوظيفة **بتتشال** في الحالات دي:

- المسمى مش من الأدوار بتاعتك، أو Senior/Lead.
- المكان بره مصر والخليج وأوروبا، أو ريموت بس لدولة تانية (زي US only).
- طالبة أكتر من 4 سنين خبرة.
- طالبة لغة غير الإنجليزي والعربي بشكل إلزامي (ألماني مثلاً)، أو الإعلان نفسه مش مكتوب بالإنجليزي.
- في أوروبا: لو الإعلان قايل صراحة إن مفيش visa sponsorship.
- في الخليج: لو الوظيفة للمواطنين بس.

وكل الأسباب دي بعددها بتظهر في تبويب "المصادر".

**نسبة التوافق** معناها: من المهارات اللي الوظيفة طالباها، قد إيه منها عندك. الشهادات بتتحسب بنص الوزن.

## ملاحظات

- **LinkedIn وWuzzuf** مش بيتسحب منهم، لأن شروط استخدامهم بتمنع ده. بدل كده فيه روابط بحث جاهزة في تبويب "ابحث بنفسك".
- **بوستات الـ HR والـ recruiters** (بوستات "We are hiring" على LinkedIn) ليها قسم لوحدها في أول تبويب "ابحث بنفسك". بتبحث في البوستات نفسها، مرتبة بالأحدث، وموزعة على مصر والخليج وريموت/relocation. الكلمات اللي بتبحث بيها موجودة في `config/profile.yml` تحت `post_roles` و`post_places`.
- العلامات اللي بتحطها على الوظايف (قدمت، محفوظة، مش مناسبة) بتتحفظ في المتصفح بتاعك بس. يعني لو فتحت الموقع من موبايل تاني، مش هتلاقيها.
- الـ repo public، فبلاش تحط فيه رقم تليفونك أو الإيميل أو ملف الـ CV نفسه.
- GitHub بيوقف الـ workflows المجدولة لو الـ repo فضل 60 يوم من غير أي نشاط. لو ده حصل، فعّله تاني من تبويب Actions.

## على جهازك

```bash
pip install -r requirements.txt
python -m pytest -q tests      # اختبارات الفلترة
python -m radar.run            # تشغيل حقيقي (محتاج إنترنت)
python -m radar.run --demo     # بيانات تجريبية من غير إنترنت
cd docs && python -m http.server 8000   # افتح http://localhost:8000
```
